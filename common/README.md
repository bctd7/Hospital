# 公共组件

这里只放跨服务复用的技术能力，例如错误码、认证基础结构、事件信封和可观测性适配。

当前已建立：

- `observability/logging`：功能日志事件、公共字段和请求上下文；
- `observability/httpaccess`：脱敏 HTTP 访问日志和 Request ID 中间件。

不要放入：

- 任何具体业务服务的 Logic；
- 跨服务共享的数据库 Model；
- 为了少写几行代码而抽出的不稳定工具函数；
- 依赖某个服务 `internal` 包的代码。

除已经明确跨所有服务统一的能力外，优先把代码留在服务内部；重复和边界稳定后再上移。
