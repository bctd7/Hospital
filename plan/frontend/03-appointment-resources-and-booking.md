# 检查资源与预约

## 工作人员资源管理

管理端业务关系是“科室 -> 房间 -> 可执行检查项目”。资源主页稳定状态只显示两栏：

1. 初始为“科室 | 房间”；
2. 点击房间后，科室栏向左退出，房间栏移到左侧，项目栏从右侧进入；
3. 稳定后为“房间 | 检查项目”，顶部显示科室与房间面包屑；
4. 切换房间只刷新右侧项目；
5. 返回科室播放反向动画。

资源主页不允许三列常驻，也不恢复“管理当前房间”“查看停用资源”、房间停用开关或同义底部主按钮。现有
新增、编辑入口保留在对应列表和详情页；房间详情只提供一次性的“不再使用此房间”，不展示停用资源列表，也
不提供恢复开关。

房间详情必须完整展示并编辑院区、楼栋、楼层和房间号。可执行项目只关联已经通过导诊管理流程建立的本科室项目；
这里不能直接新建、复制或快速克隆项目，只建立“该房间可以执行该项目”的关系。项目基本信息仍由 Appointment
拥有，移动的是工作人员端入口和操作顺序，不是后端数据归属。项目与 Guidance 规则通过一次性分布式事务全部
提交成功后才对资源管理可见；事务的预提交记录和失败记录不能出现在可关联项目列表中。

项目基本信息同时维护预计检查时长，单位为分钟，允许范围 5～480 且必须按 5 分钟递增。管理端使用原生档位
选择器，不允许自由输入数字；资源总览的项目卡片和房间详情的可执行项目列表均直接展示该时长。它用于预期
展示和后续智能导诊估算，不参与房间容量计算。

项目的通用 `description` 不再解释为 Appointment 项目简介或在房间资源页维护。它迁入导诊管理第三步，作为
Guidance 拥有的自然语言规则说明：患者直接阅读原文，后端使用确认后的结构化拆解结果参与排序。Appointment
只保留项目名称、所属科室、预计时长及资源配置所需事实。

## 周配置

房间周窗口和项目周窗口分别编辑：

- 房间：星期、上午/下午、开放起止时间、共享容量；
- 项目：星期、上午/下午、预约开始、停止新增和结束时间；
- 选择上午时默认 09:00～12:00，选择下午时默认 13:00～18:00，使用按 5 分钟递增的选择器调整；
- 项目的“停止新增”同时是停止患者检查报到的时间；
- 时间选择器确认单个字段后保持编辑面板，不提前退出页面；
- 前端先校验 12:00 边界和项目窗口包含关系，后端 400/409 仍需展示明确中文错误。

## 患者预约

患者端采用相反阅读顺序：“院区/科室 -> 检查项目 -> 可用房间 -> 本周日期与上午/下午”。患者自己选择房间，
不选择医生，后端也不做最优房间分配。

页面只展示真实可预约选项：项目存在但当前没有完整可用配置时以灰色不可选状态展示，并说明缺少可用房间
或时间，而不是把空数据误判为接口失败。

提交前展示项目、科室、严格地址、日期、大窗、时间和预计检查时长。创建、取消、列表和详情均调用真实
Appointment 接口；成功后刷新本人预约和消息未读数。

同一患者可以在同一日期和大窗预约多个不同检查项目。同一项目在该日期和大窗已有待检查或检查中预约时，
前端展示明确的重复提示；换房间不会绕过限制。完成、取消或未到场后允许再次预约，但每次成功预约仍重新
消耗周额度。

## 预约列表

- 患者“我的预约”：只看当前账号自己的记录；
- 工作人员“科室预约”：按当前科室查看所有患者；
- 患者活跃列表展示待报到、排队中、正在叫号和检查中；报告待完成、已完成和未到场进入检查记录；
- 患者在项目开始至停止新增时间执行“检查报到”。所有项目都先自动判断是否配置第三步“患者提醒”：存在提醒时
  先展示具体提醒并要求患者确认，没有提醒时不显示弹窗并直接提交报到。准备状态的就绪提示和项目先后关系中的患者
  文案不混入该弹窗。报到后显示候检号、当前叫号和前方人数；
- 工作人员“科室预约”默认今天，按房间展示互斥的当前叫号/当前检查面板、候检队列、尚未报到人员，以及位于其下方的未到场人员；顶部采用左侧可收缩科室信息、右侧单行紧凑操作区，“切换科室”和“刷新”不得被长科室名称挤成竖排；
- 患者端和工作人员端均显示一分钟叫号倒计时；截止后自动刷新后端状态。窗口结束前过号患者返回候检队列，
  不得误放入代表从未报到的“尚未报到”；窗口结束后的正在叫号预约进入未到场和检查记录；
- 已经报到但尚未叫号的患者继续保留在房间当日候检队列，上午未叫到可以在下午继续排队；窗口结束不会把这类
  已报到患者自动转成未到场；
- 工作人员可以查看其他日期但只能读取，只有今天允许叫下一位、开始检查和结束检查；
- 从科室预约页结束检查成功后，直接进入该预约的报告编辑详情，不要求工作人员再到检查记录中寻找；
- 已取消保留后台事实和科室消息，不进入普通预约列表；检查记录继续提供患者关键字搜索。
- “我的预约”、科室预约详情和消息卡片读取预约时长快照，统一显示“预计用时约 N 分钟”，不会因项目后来修改而变化。
