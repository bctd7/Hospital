# 检查资源与预约

## 工作人员资源管理

管理端业务关系是“科室 -> 房间 -> 可执行检查项目”。资源主页稳定状态只显示两栏：

1. 初始为“科室 | 房间”；
2. 点击房间后，科室栏向左退出，房间栏移到左侧，项目栏从右侧进入；
3. 稳定后为“房间 | 检查项目”，顶部显示科室与房间面包屑；
4. 切换房间只刷新右侧项目；
5. 返回科室播放反向动画。

不允许三列常驻，也不恢复“管理当前房间”“查看停用资源”、房间停用开关或同义底部主按钮。现有新增、编辑
入口保留在对应列表和详情页。

房间详情必须完整展示并编辑院区、楼栋、楼层和房间号。可执行项目只关联已经在本科室创建的项目；这不是
复制项目，而是建立“该房间可以执行该项目”的关系。

## 周配置

房间周窗口和项目周窗口分别编辑：

- 房间：星期、上午/下午、开放起止时间、共享容量；
- 项目：星期、上午/下午、预约开始、停止新增和结束时间；
- 选择上午时默认 09:00～12:00，选择下午时默认 13:00～18:00，仍允许手动调整；
- 时间选择器确认单个字段后保持编辑面板，不提前退出页面；
- 前端先校验 12:00 边界和项目窗口包含关系，后端 400/409 仍需展示明确中文错误。

## 患者预约

患者端采用相反阅读顺序：“院区/科室 -> 检查项目 -> 可用房间 -> 本周日期与上午/下午”。患者自己选择房间，
不选择医生，后端也不做最优房间分配。

页面只展示真实可预约选项：项目存在但当前没有完整可用配置时以灰色不可选状态展示，并说明缺少可用房间
或时间，而不是把空数据误判为接口失败。

提交前展示项目、科室、严格地址、日期、大窗和时间。创建、取消、列表和详情均调用真实 Appointment 接口；
成功后刷新本人预约和消息未读数。

## 预约列表

- 患者“我的预约”：只看当前账号自己的记录；
- 工作人员“科室预约”：按当前科室查看所有患者；
- 活跃列表保留待检查和检查中两个状态；
- 已完成和未到场进入诊后记录；已取消保留后台事实和科室消息，不进入普通预约列表；
- 工作人员列表提供患者关键字搜索及现有日期、状态等筛选。
