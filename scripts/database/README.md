# 数据库与综合体验数据

本目录统一维护本地数据库初始化、压平迁移校验和可重复的综合体验数据。数据库结构以 `migrations/` 为准，
灌数 SQL 只服务联调与客户体验，不承担结构迁移。

## 常用命令

```powershell
.\scripts\database\bootstrap-local.ps1
.\scripts\database\migrate.ps1 -Service identity -Direction version
.\scripts\database\migrate.ps1 -Service appointment -Direction up
.\scripts\database\migrate.ps1 -Service guidance -Direction up
.\scripts\database\validate-flat-migrations.ps1
.\scripts\database\seed-comprehensive-test-data.ps1 -Reset
```

- `bootstrap-local.ps1`：启动本地 MySQL，创建三个服务数据库与账号并执行最新迁移；
- `migrate.ps1`：显式选择服务与 `up/down/version`；
- `validate-flat-migrations.ps1`：确认每个服务只保留一对 `000001`，up/down 对称且综合数据不引用旧表；
- `seed-comprehensive-test-data.ps1`：只允许在 `APP_ENV=local` 下使用；`-Reset` 会重建三个数据库并清理 Redis
  中的会话、授权版本和 Appointment 缓存。

  未到场记录、当前待检查和未来预约，便于在工作人员端与患者端之间切换演示。

数据库只保存规范化手机号的 HMAC 指纹和脱敏快照，不保存手机号明文。服务器灌数从 `.env.production` 读取两名

脚本不会按 153 号段猜测角色，也不会为同一手机号创建第二个账号。

另外预置多名虚假医生和患者，用于形成候检队列、叫号、检查中、报告待写、未到场和取消等展示密度。

## 医院、资源与时间范围

- 仅建立一个院区：`上海市第二人民医院`；
- 地点严格限定为 `1号楼`、`2号楼`、`3号楼`，房间继续保存楼栋、楼层和房间号；
- 建立放射科、超声科、内镜中心、检验科、功能检查科和妇科；
- 所有活动房间和项目均配置周一至周日的上午、下午窗口，周六和周日可直接测试；
- 预约覆盖过去检查完成与正式报告、报告更正、未到场、取消、当前待报到/候检/叫号/检查中/报告待写，
  以及未来一至两天的待检查记录；
- 保留八种预约状态、候检队列、过号顺延、消息已读游标、报告草稿、正式版本和更正版本。

## 检查项目与准备要求

体验数据完整包含客户 Excel 中的十五类项目：抽血化验、尿常规/尿培养、粪便常规/隐血、腹部 B 超、泌尿系或
妇科经腹 B 超、胃镜、肠镜、增强 CT/MRI、心电图、胸片/普通 X 线、肺功能、脑电图、糖耐量试验、血压测量、
妇科检查/白带/TCT/HPV；同时保留胸部 CT、冠状动脉 CTA、甲状腺彩超等演示项目。

准备规则只把禁食、禁水和饮水作为排序状态。清肠用药、妊娠可能、避开月经期、留取标本和排空膀胱作为患者
提醒展示，不伪装成新的硬排序状态。Excel 外补充内容以医院或政府卫生机构公开资料交叉核对：

- [北京市中医药管理局：空腹采血与腹部超声注意事项](https://zyj.beijing.gov.cn/ylfw/ysbj/201912/t20191223_1413112.html)；
- [北京市卫生健康委员会：体检空腹时间说明](https://wjw.beijing.gov.cn/bmfw_20143/jkzs/jksh/202501/t20250114_3988316.html)；
- [济南市政府：腹部及泌尿妇科超声检查须知](https://qsy.jinan.gov.cn/colqsy10933/art/2025/art_qsy10933_qsy60708.html)；
- [清华长庚医院：胃肠镜检查准备](https://www.btch.edu.cn/yblm/jkxj/15217.htm)；
- [烟台市政府：尿液与粪便标本留取说明](https://www.yantai.gov.cn/art/2025/3/4/art_67955_3022876.html)。

这些资料用于构造体验数据，不替代医院最终审核。正式上线前仍应由上海市第二人民医院工作人员在三步项目配置
中确认自然语言说明、结构化规则和患者提醒。
