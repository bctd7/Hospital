# 数据库与综合测试数据

本目录统一处理本地数据库初始化、版本迁移和可重复的综合联调数据。数据库结构以 `migrations/` 为准，SQL 灌数
只服务体验与测试，不承担结构迁移。

## 命令

```powershell
.\scripts\database\bootstrap-local.ps1
.\scripts\database\migrate.ps1 -Service identity -Direction version
.\scripts\database\migrate.ps1 -Service appointment -Direction up
.\scripts\database\migrate.ps1 -Service guidance -Direction up
.\scripts\database\validate-flat-migrations.ps1
.\scripts\database\seed-comprehensive-test-data.ps1 -Reset
```

- `bootstrap-local.ps1`：启动本地 MySQL、创建三个服务数据库与账号并执行最新迁移；
- `migrate.ps1`：显式选择服务与 `up/down/version`，日常不要直接调用 Go 迁移器；
- `validate-flat-migrations.ps1`：确认每个服务只有一对 `000001`，up/down 表完全对称，综合数据不引用旧表；
- `seed-comprehensive-test-data.ps1`：只在 `APP_ENV=local` 下写入综合体验数据，`-Reset` 会重建三个数据库并清理相关 Redis 缓存。

综合测试数据仅允许在 `APP_ENV=local` 使用。它包含多院区、多科室、医生、患者、检查资源、完整预约状态、
预约与科室消息、草稿、正式及更正报告，以及项目准备规则和跨科室先后关系。首次向空库写入可直接执行；需要清理旧测试数据并按压平后的
`000001` 迁移重建时，显式使用 `-Reset`。该模式也会清空本地 Redis 中的登录会话、授权版本和 Appointment 缓存，
避免固定测试账号复用旧缓存。

```powershell
.\scripts\database\seed-comprehensive-test-data.ps1
.\scripts\database\seed-comprehensive-test-data.ps1 -Reset
```

## 智能导诊联调组合

使用 `13482154556` 登录并切换到患者端。提前规划建议选择今天之后、本周之内的日期，避免账号今日已有三条预约
触发重复预约保护。

### 傻瓜式验收顺序

以下步骤分别验证智能解析、提前规划和当日导诊。只查看方案不会创建预约；只有点击“采用此方案”才会真正占用
容量和本周额度。

1. **智能解析说明（工作人员端）**
   - 首页进入“导诊管理”，切换到检验科并编辑“肝功能检查”；前两步保持原值，进入“检查准备规则”；
   - 临时输入“检查前需空腹 8～12 小时；请按医嘱提前服药；怀孕或可能怀孕请提前告知工作人员”，点击
     “智能解析说明”；
   - 应看到禁食和禁水两条规则，均采用相对检查时间的 `8～12 小时`，来源显示“模型解析”；提前用药和怀孕分别
     进入患者提醒，不得成为新的规划状态；
   - 本步骤只做预览，不点击“一次性保存并发布”，即可保持测试数据不变。
2. **直接先后关系（患者端）**
   - 进入“智能导诊 → 提前规划”，跨科室选择“血常规”和“冠状动脉 CTA”；
   - 选择本周未来一个未预约日期，只保留上午，生成方案；
   - 所有候选方案都必须是血常规在前、冠状动脉 CTA 在后，并显示从 3 号楼到 1 号楼的移动信息。
3. **准备状态与成熟时间（患者端）**
   - 选择“肝功能检查、腹部彩超、泌尿系彩超”，选择本周未来一个未预约日期的全天；
   - 优先方案应把肝功能和腹部彩超安排在上午，把泌尿系彩超安排在下午；当前综合数据的参考时刻通常为
     `09:00–09:15 → 09:20–09:45 → 14:00–14:20`；
   - 这证明空腹/禁水项目先集中完成，饮水准备从最后一个禁水项目完成后重新计算，并在可行范围内优先获得更充分
     的准备时间；
   - 把同一天改为“仅上午”再次生成，应明确提示“当前选择无法生成预约方案”，不能硬塞出不可执行方案。
4. **当日导诊与地图串联（患者端）**
   - 在智能导诊顶部切换到“当日导诊”；
   - 应依次看到“血常规 → 冠状动脉 CTA → 泌尿系彩超”，地点依次为 3、1、2 号楼；
   - 点击“采用方案 → 导入地图”，选择院外出发地址后，检查导航应先从院外起点前往第一个检查地点，并允许完成
     一段后继续切换到下一检查地点。

当日导诊数据具有自然日期边界。若已经操作过三条预约，或当天标准上午/下午窗口已经结束，可在下一个可用大窗前
重新执行 `seed-comprehensive-test-data.ps1 -Reset`。重建会清空本地登录会话，但会恢复完整测试数据；三条导诊预约
使用标准上午 `09:00–12:00` 或下午 `14:00–17:00` 窗口，不再绑定灌数时刻前后各半小时。

| 验证目标 | 选择项目 | 候选时段 | 预期结果 |
|---|---|---|---|
